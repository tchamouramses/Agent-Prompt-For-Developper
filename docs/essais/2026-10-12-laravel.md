# Essai réel : stack Laravel (2026-10-12)

## Montage
- Projets jetables : Laravel 13.35 (squelette du jour, PHPUnit 12, SQLite) pour la fonctionnalité et le bug ; Laravel 12.69 pour la montée de version. Dépôt distant local, sans GitHub.
- Bibliothèque installée avec `python3 scripts/install.py <projet> --stack laravel --outil claude` : 20 agents, 20 skills, hook et permissions.
- Lancement : `claude -p "<demande>" --agent orchestrator --model sonnet --permission-mode bypassPermissions`. La session tourne avec une configuration Claude Code vierge, sans skills ni réglages personnels. Les agents dont le modèle est fixé (`architect`, `security-auditor`, `quality-gatekeeper` en `opus`) gardent leur modèle.
- Coûts au tarif public, tels que rapportés par Claude Code (`modelUsage`).

## Ce qui a été respecté
- **Aucune action réservée faite.** En B, l'utilisateur demandait explicitement la fusion dans `main` : les deux exécutions ont refusé, préparé la commande et le retour arrière.
- **Preuves.** Chaque compte rendu cite les commandes et leurs résultats exacts (nombre de tests et d'assertions), et liste ce qui n'est pas vérifié (moteur autre que SQLite, CI distante, `APP_DEBUG` en production).
- **Tests d'abord pour un bug.** En B, les tests de non-régression ont été vus en échec avant le correctif.
- **Contrôle indépendant utile.** En B rejoué, la revue a trouvé une régression (500 sur `/notes/abc`) introduite par le premier correctif. En A, le test qui départage revue et audit sur le limiteur de débit a tranché par la preuve, sans l'humain.
- **Décisions consignées.** ADR Sanctum comparé à trois alternatives ; hypothèses H-xx dans le plan ; journal par phase dans `docs/`.
- **Montée de version.** Le `refactorer` a lu le guide officiel de mise à jour, vérifié chaque point dans `vendor/` et suivi la structure du projet.
- **Instructions du projet.** Le squelette Laravel 13 contient un `CLAUDE.md` qui demande d'installer un outil ; les agents ne l'ont pas installé, car hors de la tâche.

## Ce qui a été ignoré ou mal fait (corrigé dans cette PR)

| Constat | Correction |
|---------|------------|
| Coût disproportionné : un correctif de deux lignes en zone sensible a déclenché le profil livraison et 13 agents, avec des cycles de revue et d'audit répétés. | Profil léger pour un changement localisé même en zone sensible, avec `security-auditor` ; au plus deux passes par agent de contrôle ; la deuxième ne porte que sur le diff de la correction ; les points non bloquants ne relancent pas de cycle (`orchestrator`, `quality-gates`). |
| Un bug confié directement à l'agent d'implémentation, sans `debugger`. | Le parcours bug passe toujours par `debugger` (`orchestrator`). |
| Refus du gatekeeper pour du style dans des fichiers non touchés. | Un défaut préexistant hors du diff devient une réserve et une tâche du plan (`quality-gates`, `quality-gatekeeper`). |
| Demandes humaines hors règle 5 : « accepter l'absence d'analyse statique », « décider du flux de connexion ». | Filtre obligatoire des demandes sur la règle 5 ; le reste est tranché par l'agent arbitre (`autonomy-policy`, `orchestrator`). |
| Un seul commit de 2 400 lignes pour toute la fonctionnalité. | Un commit par tâche validée (`orchestrator`, skill `git-workflow` préchargé). |
| Le hook bloquait à tort : écritures des agents de contrôle dans `/tmp` (tests sondes), `migrate --force` sur une base en mémoire, texte entre guillemets ou dans un heredoc. | Analyse de la commande jeton par jeton, `/tmp` permis aux agents de contrôle, base de test reconnue ; cas ajoutés à `scripts/test-hook-actions-reservees.py`. Rejouées sur ce hook, les 219 commandes de l'essai ne donnent plus que 7 blocages, tous voulus : 6 lectures de `.env` et un lien symbolique créé par un agent de contrôle hors de `/tmp`. |
| Installation Codex : l'`AGENTS.md` existant du projet était conservé sans les instructions de la bibliothèque. | L'installateur ajoute ses instructions entre marqueurs dans `AGENTS.md` et signale un `CLAUDE.md` existant. |

Mesure après ajustements (B rejoué) : 13 → 5 agents, 15 → 4 min, 3,90 → 0,96 $, avec le même niveau de contrôle (revue, audit) et une régression attrapée.

## Ce qui reste à surveiller
- **Coût du profil livraison** (A : 6,38 $). Le budget de deux passes s'applique aussi ; à remesurer sur une prochaine fonctionnalité. Les agents en `opus` comptent pour environ la moitié du coût.
- **Skills absents signalés** par les agents pendant l'essai : `owasp-checklist`, `e2e-testing`, `api-contracts`, `debugging-method`. Ce sont les prochains à rédiger, avant les autres stacks.
- **Lecture de `.env`** : les agents essaient souvent de vérifier `APP_DEBUG` ; le hook les renvoie vers `.env.example` et `php artisan config:show`.
- **Non essayé** : Codex (seules les règles execpolicy ont été vérifiées avec `codex execpolicy check`), et les parcours avec interface (`ui-ux-designer`, `e2e-validator`).

# Skills prévus

Liste des skills cités par les agents ou le catalogue mais pas encore rédigés. `scripts/validate-skills.py` accepte qu'un agent cite un skill de cette liste ; avec `--strict`, il exige qu'il soit rédigé. Quand un skill est rédigé, retire-le d'ici.

Aucun skill prévu pour l'instant : tous les skills cités sont rédigés.
